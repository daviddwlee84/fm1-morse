MORSE on the web

See what your FM-1 reads, send it text to copy, and back up what it has learnt in MORSE. Chrome or Edge on a computer, the FM-1 running MORSE (backups: 0.4 or later) on USB, or on Bluetooth with 0.5. Nothing to install.

No FM-1 at hand? Try MORSE in the browser · Cheatsheet: every page and button

1. Connect

not connected

Connect finds it on USB, or on Bluetooth once the computer has connected it (on a Mac: Audio MIDI Setup, Window, Show MIDI Studio, the Bluetooth button). With both, USB is used. The browser asks to use MIDI devices with system exclusive messages: allow it.

Over Bluetooth, directly (MORSE 0.5 or later): the browser finds the FM-1 itself, no system setting (Web Bluetooth). Pick FM-1 XXXX in the list. Only this page talks to it then: Vail and other programs need Connect.

2. Live

What the FM-1 reads: key on its KEY page, or type on its TYPE page (there each letter comes as you press it, before it has played).

Decoded on this page, from the keying alone (as Vail would), with the speed and spacing it measures:

Send text: the FM-1 plays it as received (amber on its KEY page), at its hearing speed. <SK> runs letters together as one prosign.

Timing: how exactly the keying arrives

Each press and gap the browser received, in ms: by the event's time stamp, and (after the slash) by when the page got it. The FM-1's TYPE page plays exact lengths (a dit is 1200 / WPM ms, a dah three, the gap inside a letter one), so play some letters there and compare. Over Bluetooth the arrival times wander by a connection interval; the time stamps should not.


      

    

  


  

    
3. Back up

    

      

    
Nothing changes on the FM-1. The file is plain JSON: every letter's two boxes (0..5), the rounds,
      and from MORSE 0.7 the settings (speeds, keyer, start page, ...).
      Only show it reads it into the chart below without saving a file.

  


  

    
4. Restore

    

      

    
The FM-1 shows what it got and asks: press PLAY on it to load, HOME to keep what is there.
      A file with settings loads them too on MORSE 0.7 or later; older MORSE takes the progress alone.

  


  

    
With Vail

    
Vail is a Morse repeater in the browser: key to other people, or to its
      decoder, and train words, call signs and QSOs at training.vailmorse.com.
      The FM-1 is a key to it, with nothing to set up: open Vail in Chrome or Edge with the FM-1 connected (USB, or
      Bluetooth through the system as for Connect), choose Straight Key as Vail's mode (the FM-1's own
      keyer already times paddles), and key on the FM-1's KEY page, or play letters and phrases on its TYPE page. This
      page can stay open beside it.

    

      
PRESET on the FM-1Hearing (characters / overall)For

      
START20 / 8 WPMlearning the letters by sound: each letter fast, long gaps between them

      
BUILDING20 / 13most letters known; gaps shrinking

      
QSO22 / 18talking to people: from here Vail's decoder joins the letters into words

      
FAST25 / 25standard spacing

    

    
The second number stretches the gaps between letters (Farnsworth), not the letters. Vail's decoder
      takes a long enough gap as a word space: in our test 20 / 14 (a gap of 6.4 dits) still gave one letter per word,
      22 / 18 (4.8 dits) gave words. The decoder above shows the gap it measured in dits. To be read by others, use QSO or FAST, or turn K2
      up to the character speed. The send speed (K4) only matters for paddles on the KEY page.
