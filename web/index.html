MORSE on the web

See what your FM-1 reads, send it text to copy, and back up what it has learnt in MORSE. Chrome or Edge on a computer, the FM-1 running MORSE (backups: 0.4 or later) on USB, or on Bluetooth with 0.5. Nothing to install.

1. Connect

not connected

Connect finds it on USB, or on Bluetooth once the computer has connected it (on a Mac: Audio MIDI Setup, Window, Show MIDI Studio, the Bluetooth button). With both, USB is used. The browser asks to use MIDI devices with system exclusive messages: allow it.

Over Bluetooth, directly (MORSE 0.5 or later): the browser finds the FM-1 itself, no system setting (Web Bluetooth). Pick FM-1 XXXX in the list. Only this page talks to it then: Vail and other programs need Connect.

2. Live

What the FM-1 reads: key on its KEY page, or type on its TYPE page.

Send text: the FM-1 plays it as received (amber on its KEY page), at its hearing speed. <SK> runs letters together as one prosign.

Timing: how exactly the keying arrives

Each press and gap the browser received, in ms: by the event's time stamp, and (after the slash) by when the page got it. The FM-1's TYPE page plays exact lengths (a dit is 1200 / WPM ms, a dah three, the gap inside a letter one), so play some letters there and compare. Over Bluetooth the arrival times wander by a connection interval; the time stamps should not.
